# 🧪 Чек-лист тестирования SauceDemo

Данный чек-лист содержит основные сценарии для проверки функциональности веб-приложения [SauceDemo](https://saucedemo.com).

---

### 🔑 1. Авторизация
- [ ] **1.1** Страница входа открывается корректно
- [ ] **1.2** Поле `Username` доступно для ввода
- [ ] **1.3** Поле `Password` доступно для ввода
- [ ] **1.4** Кнопка `Login` активна
- [ ] **1.5** Успешный вход с валидными данными (`standard_user`)
- [ ] **1.6** Появление ошибки при вводе неверного пароля
- [ ] **1.7** Появление ошибки при попытке входа с пустыми полями


### 🛒 2. Каталог товаров
- [ ] **2.1** Список товаров загружается и отображается
- [ ] **2.2** Наличие названия у каждого товара
- [ ] **2.3** Наличие цены у каждого товара
- [ ] **2.4** Наличие кнопки `Add to cart` для всех позиций
- [ ] **2.5** Товар успешно добавляется в корзину при клике
- [ ] **2.6** Работа всех режимов сортировки (A-Z, Z-A, Price Low-High, etc.)
- [ ] **2.7** Переход на детальную страницу товара при клике на название/фото
- [ ] **2.8** Кнопка `Back to products` возвращает пользователя в каталог

### 🛍️ 3. Корзина
- [ ] **3.1** Страница корзины открывается при клике на иконку
- [ ] **3.2** Возможность удаления товара из корзины (кнопка `Remove`)
- [ ] **3.3** Счетчик на иконке корзины отображает актуальное количество товаров
- [ ] **3.4** Кнопка `Checkout` перенаправляет на следующий этап

### 🧾 4. Оформление заказа (Checkout)
- [ ] **4.1** Страница ввода данных (`Information`) открывается
- [ ] **4.2** Поля `First Name`, `Last Name` и `Zip/Postal Code` доступны для ввода
- [ ] **4.3** Валидация: ошибка при попытке продолжить с пустыми полями
- [ ] **4.4** Успешный переход на страницу `Overview` после ввода данных
- [ ] **4.5** Отображение финального сообщения («Thank you for your order!») после завершения
